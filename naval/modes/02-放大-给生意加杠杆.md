# 模式 02 · 放大：给生意加杠杆

## 适合谁

已经有稳定收入的生意：个体户、工作室、咨询和服务、小公司、电商、门店……

共同的问题：**生意离不开老板本人**。老板休息，生意就停。

核心判断来自纳瓦尔："You're not going to get rich renting out your time." 和 "Earn with your mind, not your time."

## 第 1 步：访谈（两轮，每轮最多 5 题）

**第一轮：生意现状**
1. 你卖什么、卖给谁？一年营收和利润大概在什么区间？（给区间就够，不方便说可以跳过）
2. 客户主要从哪里来？（转介绍、平台、内容、销售、老客户复购……）
3. 如果你休假一个月、完全不管，生意会怎样？哪些环节会停？
4. 你每周的时间主要花在哪？列出前 5 件事，各占几小时
5. 客户为什么选你，而不是选同行？他们原话怎么说？

**第二轮：杠杆现状**
6. 团队几个人、各做什么？哪些事目前只有你能做？
7. 用了哪些软件、自动化或 AI？哪些流程还在靠人工重复做？
8. 有没有在做内容？谁在做？带来过客户吗？
9. 能投入的钱和时间，上限是多少？
10. 你想放大到什么程度，为什么？（更多钱、更多自由时间、更大影响，选最重要的一个）

规则：
- 数字以用户给的为准，没给的标【待补数据】，**不替用户估算营收**
- 第 4 题答得太笼统时，请用户回想上周，按天说

## 第 2 步：分析

### 2.1 时间审计

把老板每周前 5 件事分成四类：

| 类别 | 含义 |
|---|---|
| 只有你能做 | 关键判断、关键关系、你的特长本身 |
| 可以交给人 | 有规则、可以培训的事 |
| 可以交给代码 | 重复、有固定步骤的事：软件、自动化、AI Agent |
| 可以变成媒体 | 你在反复讲同样的话：讲一次，做成内容，让它反复被看 |

算出：老板每周有多少小时还在"出租时间"（后三类之和），占总工时的比例。

### 2.2 四种杠杆体检

| 杠杆 | 现在用了多少 | 证据（用户原话或数字） | 最大的机会 | 风险 |
|---|---|---|---|---|
| 人力 | 低 / 中 / 高 | | | |
| 资本 | | | | |
| 代码 | | | | |
| 媒体 | | | | |

判断顺序：**先看代码和媒体，再看人力，最后看资本**。纳瓦尔提醒过："Labor leverage will impress your parents, but don't waste your life chasing it." 招人之前，先问能不能用代码或媒体解决。

### 2.3 找瓶颈

从体检里选出**一个**最卡增长的瓶颈，说明为什么是它，不是别的。

### 2.4 把你的特长产品化

纳瓦尔的说法是 "Productize yourself"。找出老板身上客户真正买单的那部分特长（参考第 5 题的回答），看它能变成哪种不依赖老板在场的形式：
- 标准化的服务包或流程（交给人）
- 工具或系统（交给代码）
- 内容（交给媒体，同时带来客户）

## 第 3 步：按固定格式输出

```

## 时间审计

| 事情 | 每周小时 | 归类 | 可以交给谁 / 什么 |

## 四种杠杆体检
（2.2 的表格）

## 最大的瓶颈
……（理由，附证据）

## 你的特长可以变成什么
```

## 本模式额外红线

- 不建议借钱扩张；涉及融资、贷款、股权的，只做思路讨论，具体操作建议找专业顾问
- 招人建议要考虑现金流：用户没给数据时，提醒先算清楚再招
- 不推荐具体的付费软件或服务商，只说"什么类型的工具"
