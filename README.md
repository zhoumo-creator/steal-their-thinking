# 把名人的思维模型变成可复制提示词

### Steal Their Thinking

**不是背名言，而是让 AI 用他们的思路，替你想一遍你自己的事。**

</div>

## 这是什么

每一位人物，都被做成一个可以直接装进 AI 的 **Skill**：

- **先问再答**：先访谈你的情况，再给分析，不说放之四海皆准的空话
- **按人分模式**：同一个思维模型，学生、老板、CEO 的用法不一样，分开写
- **落到行动**：每次都以一份你明天就能开始做的计划结束
- **原话可查**：引用的原话都核对过出处，不编造名人语录

## 怎么用

以纳瓦尔为例，在 Claude Code 里：

```bash
git clone https://github.com/zhoumo-creator/steal-their-thinking.git
cp -r steal-their-thinking/naval ~/.claude/skills/
```

然后对它说："用纳瓦尔的方法帮我看看……"

其他工具的用法，见每位人物页面的「怎么用」。
